A small follow-up to 0.9.0.

- About no longer squeezes its links when a new version's notes are open; the page scrolls instead.
- When an event or meeting link fails to open, the message now has the heading line to itself instead of shortening the date to "Frid…".
- The README and release guide describe what's new in 0.9.0.

On 0.9.0, Check for Updates in Settings → About shows these notes under "What's new" before you install.
