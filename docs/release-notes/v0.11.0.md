Start a new event from any app, join your meeting from the menu bar, and tick off reminders.

New event from anywhere
- Record a shortcut for "New event" in Settings → General. Pressing it opens the calendar straight into quick add, from whatever app you are in.
- Pressing it again while you type keeps the calendar open, so the event you are writing is never lost.

Join from the menu bar
- Right-click the menu bar item while a meeting with a link is on, or still to come today, and Join it from the top of the menu, as in "Join Design review at 3:00 PM".

Reminders
- Reminders in the day list have a circle in their list's color. Click it to mark the reminder done in Reminders.
- Undo stays next to the day for 30 seconds, as it does after adding an event.

Smaller changes
- The menu bar item does less work each minute.
